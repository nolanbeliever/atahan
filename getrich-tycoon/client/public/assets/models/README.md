# High-detail vehicle models

Put `.glb` files here (Draco compression is supported) and list them in
`client/src/data/highDetailVehicles.ts`. The game only loads files that exist in this folder
(checked at build time), and keeps the built-in procedural car for every vehicle without a file.

Only use models you are allowed to use (check the licence on Sketchfab / Poly Pizza / CGTrader,
and credit the author where the licence asks for it).
