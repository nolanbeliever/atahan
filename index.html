Controls

Keyboard & mouse

WASD move · Mouse look (click to capture)
Shift sprint · Space jump / handbrake · C crouch
Left click attack / fire · R reload · 1-4 / Q / wheel weapons
E interact / enter & exit vehicles · F flashlight / headlights
V first / third person · I / Tab inventory · M map · X quick heal
H horn · Esc pause

Touch (iPad / iPhone)

Left thumb: floating joystick (push to the edge to sprint)
Right thumb: drag anywhere to look; drag across ATTACK to aim while firing
Buttons: attack, jump, crouch, use, reload, weapon, light, view, bag, map.
Driving: joystick = throttle / steer, BRAKE = handbrake, USE = exit.

Assets & credits

Every model, texture and sound in this build is generated in code at runtime: the city architecture, interiors, props, vehicles, characters and animations, procedural PBR textures (canvas), and synthesised WebAudio. No third-party art files are bundled. See ASSETS.md in the project for the manifest and how to drop in licensed GLB models.

Engine: three.js (MIT). Build: Vite (MIT). Multiplayer server: Node.js + ws (MIT).

Multiplayer

Multiplayer needs the Dead District server running (see README: npm run server). Singleplayer never needs a server.
